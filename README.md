# DodgeCreeps

This file was created using the Godot Dodge the Creeps tutorial.

My additions were a life system. The player has the chance to be hit 3 times and when the lives are spent, the game ends and restarts the menu. The character will respawn in the middle again and a text will appear telling the user how many lives are left.

An extra feature to this was that I added a 2 second respawn immunity/invincibility as I noticed the creeps would pile up the further in the level one was, so this way the user actually has a chance to defend themselves properly.
